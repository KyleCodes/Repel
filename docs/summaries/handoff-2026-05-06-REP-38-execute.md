### CLI restructure
- Deleted `apps/server/src/db/admin/cli.ts`.
- New layout under `apps/server/src/db/admin/cli/`:
  - `db.ts` — Commander wiring + inline `runClone`, `runDrop`, `runRefreshTemplate` handlers. Each handler takes a single typed input arg matching its zod schema (DR-REP-38-2). The Commander `.action(...)` callback is the parse boundary: it assembles raw input from positional args + options, calls `Schema.safeParse(...)`, prints zod issues and exits non-zero on failure.
  - `schemas/db.ts` — `CloneInput`, `DropInput`, `RefreshTemplateInput` zod schemas + inferred types (DR-REP-38-3).
  - `lib/branch.ts` — `getCurrentBranch()` and `extractTicketSlug(branch)`. Slug returns upper-case (`"REP-38"` from `kylemuldoon15/rep-38-...`).
  - `lib/env-local.ts` — `readDatabaseUrlFromEnvLocal(envFile?)`. Reads from the worktree's `.env.local` (or a custom path), strips surrounding quotes, throws on missing file / missing key / empty value. Created in T1 even though only consumed in T2/T3.
- Updated `apps/server/src/cli.ts` import to `./db/admin/cli/db.js`.
